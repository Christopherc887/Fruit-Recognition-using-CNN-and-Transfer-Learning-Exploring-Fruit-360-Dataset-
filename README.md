# Fruit Recognition Using CNNs and Transfer Learning

A computer vision project exploring fruit classification using the Fruit-360 dataset and convolutional neural networks or transfer learning, as indicated by the repository title.

## Project questions

- How do the implemented model architectures compare?
- What preprocessing and augmentation were applied?
- How well does the model generalise beyond its training images?

## Tools and methods

- Python
- convolutional neural networks
- transfer learning
- image classification

The work in this repository is the source of record for the analysis. The project documentation is being strengthened without changing existing code or inventing results.
